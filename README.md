## Описание программы (кратко)
Random Quote Generator — десктопное приложение на Python с графическим интерфейсом (Tkinter) для генерации случайных цитат. Программа позволяет просматривать мудрые высказывания, добавлять собственные цитаты в базу, фильтровать историю генерации и сохранять данные между запусками.


### Возможности (что программа умеет делать)
* **Генерация случайных цитат** из встроенной базы с отображением текста, автора и темы.
* **Добавление пользовательских цитат** с указанием:
    * текста высказывания;
    * автора;
    * темы (жанра).
* **Валидация ввода** при добавлении цитат (проверка заполнения всех полей).
* **Отображение истории** сгенерированных цитат (новые сверху).
* **Фильтрация истории** по автору или теме с «живым поиском» (автоматическое обновление при вводе текста).
* **Сохранение истории** между запусками программы в файле `history.json`.
* **Визуальная обратная связь** через всплывающие сообщения об успехе или ошибках.
* **Автоматическое обновление** интерфейса при генерации, добавлении и фильтрации данных.

## Инструкция по запуску

### Требования для запуска программы
* Python 3.6 или выше.
* Стандартные библиотеки Python:
    * `tkinter` (GUI‑фреймворк);
    * `messagebox` (модуль tkinter для всплывающих окон);
    * `ttk` (расширение для tkinter);
    * `random` (генерация случайных чисел);
    * `json` (работа с JSON‑файлами);
    * `os` (проверка существования файла).

Программа не требует установки дополнительных пакетов — все зависимости входят в стандартную поставку Python.

3. Откройте терминал или командную строку.
4. Перейдите в директорию, где сохранён файл программы.
